# rsschool-landing-page

The Rolling Scopes School learning project — the **GAMEDEMIC** landing page:
a website for a YouTube channel about board games, built with vanilla HTML, CSS and JavaScript.

The site has two pages — a home page and a game catalog — a light/dark theme,
and a fully responsive layout from 1440px down to 380px.

## Branches

- `landing-page` — part 1: semantic responsive markup, light and dark themes;
- `landing-page-part-2` — part 2: interactive features in vanilla JavaScript.
